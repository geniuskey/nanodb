## 단위별 범위

### NANoDB Core

- **계측 기반**: US-01~US-05
- **개발 지원**: US-06~US-07
- **관련 요구사항**: DAT, HOM, SUM, IMG, CAT, MEA, RES, CTX와 EVL-006~008
- **완료 경계**: 앱 기능 완료와 외부 AI 검증 실행 상태를 별도로 기록한다.

### Evidence Site

- **평가 자료**: US-08
- **관련 요구사항**: DOC-001~013, EVL-001~005
- **완료 경계**: Core의 실제 상태를 과장하지 않고 공개 가능한 정적 근거로 표현한다.
