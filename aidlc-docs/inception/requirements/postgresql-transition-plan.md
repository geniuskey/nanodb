# PostgreSQL 전환 계획

사용자가 해커톤 이후 약 1,000명 규모의 초기 사내 베타를 고려해 SQLite를 PostgreSQL로 변경하도록 승인했다. 이미지 저장소와 나머지 기능 범위는 유지한다.

- [x] 저장 기술 결정을 PostgreSQL + 단일 앱 호스트의 로컬 파일 저장소로 변경한다.
- [x] 해커톤 실행은 로컬 PostgreSQL을 사용하고 외부 유료 서비스 의존은 추가하지 않는다.
- [x] DB 연결정보를 환경 설정으로 분리하고 저장소에 비밀값을 커밋하지 않도록 요구한다.
- [x] 스키마 생성·변경을 재현 가능한 migration으로 관리하도록 요구한다.
- [x] 데모 초기화 대상을 전용 PostgreSQL 데이터와 런타임 업로드로 수정한다.
- [x] 초기 베타의 약 1,000명은 등록 사용자 목표이며, 동시성 수용은 부하 검증 전까지 보장하지 않음을 기록한다.
- [x] README, MVP·홈·제외 요구사항, 통합 요구사항과 실행 계획을 동기화한다.
- [x] Application Design의 컴포넌트, 의존성과 다이어그램을 PostgreSQL 기준으로 수정한다.
- [x] 로컬 파일 저장소, 기능 범위와 비활성화된 확장 설정은 그대로 유지한다.
- [x] Markdown, Mermaid, 링크, 잔여 SQLite 표현과 Git whitespace를 검증한다.
- [x] 상태와 감사 기록을 갱신한다.

이번 변경은 PostgreSQL 선택만 확정한다. 배포 형태, 연결 풀 크기, 사내 관리형 DB 사용 여부와 부하 시험 수치는 NFR Requirements 및 Infrastructure Design에서 정한다.
