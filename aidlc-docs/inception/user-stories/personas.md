# NANoDB 해커톤 페르소나

현재 3일 MVP에 직접 필요한 두 사용자만 정의한다. 장기 제품의 관리자·검토자 역할은 이번 범위에서 제외한다.

## P-01 로컬 데모 사용자

- **역할**: 한 명이 측정·분석자와 분석 소프트웨어 개발자 역할을 함께 수행한다.
- **목표**: SEM/TEM 이미지와 측정 근거를 저장하고, AI 개발에 바로 사용할 컨텍스트를 내보내 검증한다.
- **중요한 점**: 짧은 시간 안에 등록→측정→복원→내보내기 흐름이 재현되어야 한다.
- **제약**: 로그인·자동 측정·앱 내 AI 호출 없이 로컬 환경과 기존 AI 도구를 사용한다.
- **관련 이야기**: US-01~US-07

## P-02 해커톤 평가자

- **역할**: AI 심사자 또는 참여자 평가자다.
- **목표**: 프로젝트가 해결하는 문제, 실제 구현 기능, AI-DLC 근거, 검증 결과와 한계를 짧게 확인한다.
- **중요한 점**: 구현 완료, 외부 AI 데모 실행, 후속 비전이 섞이지 않아야 한다.
- **제약**: 로컬 앱에 직접 접근하지 못할 수 있으므로 정적 소개·근거 자료와 로컬 preview 대안이 필요하다.
- **관련 이야기**: US-08

## 범위 밖

시스템 관리자, 별도 승인자, 다중 조직 사용자와 다른 네 프로젝트 담당자는 현재 이야기의 페르소나로 만들지 않는다.
