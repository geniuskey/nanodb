# NANoDB — 소개

**NANoDB: Nano Assets, Never orphaned Database.** 반도체 SEM/TEM 이미지와 측정 근거를
축적하고, 이를 AI 기반 분석 소프트웨어 개발에 필요한 컨텍스트·검증 데이터로 재사용하는
경량 웹 애플리케이션입니다.

> 이 사이트는 해커톤 평가용 근거 자료입니다. 실제 앱은 로컬에서 실행하며, 여기 실린 화면은
> 로컬 native 실행을 승인된 demo 데이터로 캡처한 결과입니다. 공개된 서비스가 아니며
> 비밀정보·비공개 자료는 싣지 않습니다.

## 2~3분 읽기 순서

1. **문제** — 누구의 어떤 불편을 푸는가
2. **목적** — NANoDB가 무엇을 하려는가
3. **실제 기능** — 지금 코드로 동작하는 것
4. **근거** — 산출물·상태로의 연결은 [심사 근거](/evidence) 페이지에서 확인합니다

## 문제

반도체 계측 이미지(SEM/TEM)와 그 측정값은 담당자·도구가 바뀔 때마다 흩어집니다. 좌표계,
`nm/pixel` 보정 단위, 측정 규칙 같은 맥락이 파일 밖에 있으면, 다음 사람이나 AI 개발 도구가
같은 데이터를 다시 해석하느라 시간을 쓰고 실수를 반복합니다. AI로 분석 코드를 만들 때도
매번 데이터 형식·좌표계·단위를 사람이 다시 설명해야 합니다.

대상은 이미지에서 CD·Depth·Thickness를 재고, 그 결과로 분석·요약 코드를 만드는 현업
엔지니어입니다. 불편은 "새 이미지를 받을 때마다", "분석 코드를 새로 만들 때마다" 반복적으로
발생합니다.

## 목적

NANoDB는 이미지·측정·맥락 데이터가 담당자나 도구의 변화 속에서도 **흩어지지 않도록**
합니다. 이미지와 측정을 한곳에 축적하고, 좌표계·단위·계산 규칙을 포함한 재사용 가능한
개발 컨텍스트로 내보내, AI 개발 도구가 사람의 반복 설명 없이 같은 데이터를 다룰 수 있게
합니다.

## 실제 기능 (지금 동작)

- PNG/JPEG 이미지를 제조 메타데이터·`nm/pixel` 보정값과 함께 등록
- 등록 이미지를 목록에서 최신순으로 찾아 다시 열기
- 이미지 위 두 점 선택으로 CD/Depth/Thickness 측정과 실시간 preview
- 저장된 좌표·측정값을 새로고침 후에도 같은 위치에 overlay 복원
- 홈에서 실제 이미지 수·측정 수 집계 확인
- 측정이 하나 이상일 때 활성화되는 컨텍스트 ZIP 내보내기(명세·측정·개발 과제·검증 정답)

## Image → Measurement → Development Context 흐름

1. **Image** — 이미지를 메타데이터·보정값과 함께 등록합니다.
2. **Measurement** — 이미지 위에서 두 점을 선택해 실제 길이를 계산하고 저장합니다. 저장된
   측정은 원본 좌표로 복원됩니다.
3. **Development Context** — 선택 이미지의 명세·측정·개발 과제·검증 정답을 고정 네 파일 ZIP으로
   내보냅니다. 이 컨텍스트를 외부 AI 개발 도구에 그대로 넣어 분석·요약 코드를 만듭니다.

## 외부 AI 개발 검증 데모

내보낸 컨텍스트로 외부 AI 개발 도구에서 요약 CSV 생성 코드를 만들고 오프라인으로 검증하는
자산이 저장소 `validation/external-ai/`에 있습니다. 수동 설명 준비와 컨텍스트 내보내기 두
방식을 같은 과제로 비교하며, 준비 시간·추가 요청 수·검증 결과를 `pass`/`fail`/`unverified`
그대로 기록합니다. **이 데모는 앱 런타임에 연결되지 않고 모델을 자동 호출하지 않는, 앱 외부의
수동 개발 데모입니다.** 향상이나 토큰 절감을 미리 주장하지 않습니다.

## 한계

- 인증·권한은 이번 범위 밖입니다. 단일 키워드 검색·종류 필터, 측정·이미지 삭제, 항목별 표본
  수·평균·최소·최대, 화살표·원 도형 라벨링, 확대·이동, 메모 수정은 P1으로 구현을 마쳤습니다.
- 저장된 측정은 메모만 수정할 수 있습니다. 좌표·항목·값·보정값은 측정 근거이므로 불변입니다.
- 이미지 클릭 외에 원본 좌표를 직접 입력해 측정할 수도 있습니다. 태블릿·모바일 터치 측정과
  다크모드는 지원 범위가 아닙니다.
- 자동 계측·윤곽 검출은 없습니다. 측정은 수동 두 점 방식의 **미검토 참고값**이며 자동 계측의
  정답으로 취급하지 않습니다.
- 앱은 단일 호스트 로컬 파일 저장을 사용하며 multi-instance·객체 저장소·HA는 범위 밖입니다.
- 앱 내부 AI 호출·코드 실행 기능은 없습니다.
- PostgreSQL 통합 테스트와 브라우저 e2e는 로컬 PostgreSQL 16과 Chromium으로 실행해 통과를
  확인했습니다. 컨테이너 스택(`docker compose`) 기동과 GitHub Pages 실제 배포는 여전히
  **미검증**입니다. 상세 상태는 [심사 근거](/evidence)를 참고하세요.
